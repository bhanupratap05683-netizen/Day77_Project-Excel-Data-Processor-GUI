# Day 77 – Excel Data Processor GUI

**Phase 6 Capstone Project**  
84-Day Python & Advanced Excel Mastery Roadmap

## Overview
Desktop GUI tool built with tkinter that lets a finance user:
- Upload an Excel file
- Choose a processing option (clean, deduplicate, summarize, categorize, totals, filter)
- Process with pandas
- Download a clean result Excel

Includes live status, progress bar, full error handling, and one-click sample data generation.

pip install pandas openpyxl
